Phase 0 — set up the environment (before any code)
1. Confirm you have Python 3.10+: python --version
2. Create a virtual environment so dependencies stay isolated: python -m venv venv
3. Activate it (PowerShell): .\venv\Scripts\Activate.ps1
4. Install NumPy — the only runtime dependency the whole project allows: pip install numpy pytest

Phase 1 — Procedural renderer + PNG I/O (README's own Phase 1, weeks 1–3)
This is the recommended starting point because it needs zero training and gives you a working "prompt → image" loop almost immediately. The suggested build order, smallest piece first:
1. png.py — the PNG writer (chunk framing + zlib compression), verified against zlib.crc32
2. Basic drawing primitives — Bresenham line, midpoint circle
3. Perlin noise + fBm (for terrain/clouds)
4. SDF primitives + smooth-min blending (for shapes)
5. HSV↔RGB color + palette-from-prompt mapping
6. Scene compositor (layer everything with alpha-over)
7. Bitmap font for text captions
